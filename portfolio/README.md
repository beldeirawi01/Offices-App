# Portfolio

Static, dependency-free portfolio site (`index.html` + `assets/`). No build step.

## Publish on GitHub Pages
Create a repo named `beldeirawi01.github.io`, copy the contents of this folder to its root, push to `main`.
Then it is live at https://beldeirawi01.github.io. (Or use Settings → Pages on any repo and point it at this folder's contents.)
