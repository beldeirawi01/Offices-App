SauceDemo Test Automation Framework

Playwright · TypeScript · GitHub Actions

A Page Object Model framework that tests the full shopper journey on SauceDemo: login, inventory, cart and checkout. Page objects hold locators and actions, specs hold behavior and assertions, and test data lives in its own folder.

  • 30 tests across login (5), inventory and cart (5) and checkout (20), grouped in nested describe blocks that mirror the UI flow.
  • GitHub Actions runs the suite on Chromium, Firefox and WebKit on every push and pull request, and uploads the HTML report.
  • Parameterized locators such as addToCart(productSlug) cover all 6 products. Assertions are derived from input arrays instead of hardcoded counts.
  • Locators use data-test attributes, checked against the real DOM, so styling changes don't break tests.
  • Page Object Model
  • Data-driven
  • Cross-browser
  • CI/CD

Jobscribe

TypeScript · React · React Native · Express · PostgreSQL

A voice-to-invoice app for HVAC, plumbing and electrical techs. A tech records a job note on-site and the app turns it into a draft invoice, so nobody has to type it up later.

  • Full-stack build: Express API, React owner dashboard, Expo mobile app, and Prisma on PostgreSQL.
  • Pipeline: audio stored in S3, transcribed with OpenAI Whisper, then billing fields extracted as JSON by the Claude API into a draft invoice.
  • Stripe Connect direct charges and webhooks (money goes to each business's own account), Twilio SMS delivery, and a node-cron scheduler for overdue-invoice reminders.
  • Tested with Vitest and Supertest against a real Postgres database, a Playwright end-to-end suite for the dashboard, and Jest for mobile, all running in CI.
  • Stripe Connect
  • Twilio

  • Claude API
